# 💻 Computing Through Time
### An Interactive Journey Through the Evolution of Computing

Explore the fascinating history of computers—from ancient counting tools and mechanical calculators to modern personal computers and artificial intelligence.

**Computing Through Time** is an interactive educational website designed to make learning about computer history engaging, visual, and easy to understand.

## 🌐 Live Website

Download the HTML file and open it in your browser to use it.

## ✨ Features

- **Interactive Timeline:** Explore important milestones in computing history, from ancient calculating tools to modern AI.
- **Five Computer Generations:** Discover how computer technology evolved through vacuum tubes, transistors, integrated circuits, microprocessors, and AI-focused systems.
- **Historical Pioneers:** Learn about influential figures such as Ada Lovelace, Charles Babbage, Alan Turing, and Grace Hopper.
- **Programming Languages:** Explore the development of programming languages, including machine language, Assembly, FORTRAN, COBOL, C, and Python.
- **Artificial Intelligence:** Understand modern AI, its applications, benefits, and potential risks.
- **Knowledge Quiz:** Test your understanding with an interactive five-question quiz.
- **Animated Visuals:** Enjoy animated illustrations and interactive elements throughout the website.
- **Sound Effects:** Optional synthesized sound effects make the experience more interactive.
- **Responsive Design:** Designed to work on desktop computers, tablets, and mobile devices.

## 🚀 Getting Started

You can explore the website directly in your browser or run it locally.
